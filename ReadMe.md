# Lift Simulation
The Lift Simulation project replicates the external functioning of an elevator system in a building. It simulates the queue system as well.

## Tech stack

- HTML
- CSS
- JAVASCRIPT

## Key Components of a Lift Simulation Project:

- User input to set the number of lifts and floors
- Up and Down buttons to call the lift
- Door opening and closing sequences including delays
- Request Handling using queue
